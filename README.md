# PaisaBachao for Mac

Downloads of the PaisaBachao Mac app, with Gojo, the voice assistant that logs your spending when you say it out loud. This repository holds release builds only.

**[Download the latest version](https://github.com/maskfool/paisabachao-releases/releases/latest/download/PaisaBachao-arm64.dmg)** · [All releases](https://github.com/maskfool/paisabachao-releases/releases) · [Website](https://paisabachao.madebyshubham.in)

**Requirements:** a Mac with Apple silicon (M1 or later). Gojo uses your own OpenAI API key, which you add in Settings.

**First open:** the app isn't notarised by Apple yet, so macOS stops it the first time. Drag PaisaBachao into Applications and open it once, then go to **System Settings → Privacy & Security** and click **Open Anyway**.

Your financial data stays on your Mac.
